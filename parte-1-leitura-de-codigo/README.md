# Parte 1: Leitura de código

O script abaixo deveria consultar uma API e informar a média das notas de um curso (escala de 0 a 10), ponderada pelo número de respostas de cada turma. Você não precisa executar nem reescrever o código: a API é fictícia. Leia o código e a resposta de exemplo e responda às questões.

```json
[
  {"turma": "Básico A",   "nota": 9.0, "respostas": 40},
  {"turma": "Básico B",   "nota": 8.5, "respostas": 10},
  {"turma": "Avançado A", "nota": 7.0, "respostas": 25},
  {"turma": "Avançado B", "nota": 87,  "respostas": 2},
  {"turma": "Mentoria",   "nota": 9.5, "respostas": 0}
]
```

Com esses dados, o script imprime `Média ponderada do curso: 30.25`.
